Modal de Confirmación - Demo

Ejemplos de modales de confirmación con diferentes tipos y configuraciones.

Modal de Peligro (Danger)

Utiliza este tipo para acciones destructivas como eliminar o cancelar.

window.showConfirmModal({ title: '¿Eliminar ruta?', message: '¿Estás seguro de que deseas eliminar esta ruta?', confirmText: 'Eliminar', cancelText: 'Cancelar', type: 'danger', onConfirm: () => console.log('Eliminado') });

Modal de Advertencia (Warning)

Utiliza este tipo para acciones que requieren atención especial.

window.showConfirmModal({ title: '¿Cambiar configuración?', message: 'Cambiar esta configuración afectará tus preferencias.', confirmText: 'Continuar', cancelText: 'Cancelar', type: 'warning', onConfirm: () => console.log('Cambiado') });

Modal de Información (Info)

Utiliza este tipo para confirmaciones generales y acciones informativas.

window.showConfirmModal({ title: '¿Guardar cambios?', message: '¿Deseas guardar los cambios realizados?', confirmText: 'Guardar', cancelText: 'Cancelar', type: 'info', onConfirm: () => console.log('Guardado') });

Uso con Async/Await

El modal puede usarse con Promises y async/await.

async function confirmarAccion() { const confirmed = await showConfirmModal({ title: 'Confirmar', message: '¿Continuar?', type: 'info' }); if (confirmed) { console.log('Usuario confirmó'); } else { console.log('Usuario canceló'); } }
💡 Nota:

Los modales se cierran automáticamente al hacer clic fuera del contenido, presionar Escape, o hacer clic en los botones.
